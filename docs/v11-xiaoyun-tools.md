# 小云总 Agent 的工具与站内动作

文字与语音转写共用浏览器提交和 Pi 总管。明确叫出页面名时，服务直接登记页面动作。像「看全国发电量这些年的趋势」这样的请求，由 Pi 按站内视图目录匹配图表。在同一请求里明确要切页和查数时，两个结果都可以返回。浏览器接收页面编号、图表编号及筛选，校验后切换页面。首页、地球工作台、专题总览、专题详情、自定义制图、区域回放和数据审核入口都在目录中。

## 总管可以调用的 19 个工具

| 工具 | 当前作用 |
| --- | --- |
| `load_skill` | 读取看板、预测回测或 Anatomy 机制解释的运行时说明 |
| `query_data` | 委托数据库子 Agent 查已发布指标，保存本轮结果并续办澄清 |
| `inspect_data` | 检查结果范围、粒度、质量和可用图表、分析，支持分析预检 |
| `render_chart` | 按查询结果出图，允许复用旧图输入更换图形和渲染器 |
| `render_dashboard` | 从已检查的单指标结果生成看板，附数据版本、口径和来源 |
| `submit_analysis` | 提交描述统计、聚类、预测、回测、比较或选模 |
| `get_analysis` | 读取已有分析任务状态和结果 |
| `get_sources` | 从已授权结果追溯数据版本与源链接 |
| `list_available_datasets` | 列出已发布指标、单位和口径 |
| `utc_now` | 读取 UTC 时间 |
| `find_site_views` | 发现真实站内页面、图表定位点、筛选参数及覆盖 |
| `navigate_site` | 切换到已注册页面，按支持的条件定位图表 |
| `render_mechanism` | 按因果顺序生成可旋转、缩放和分步查看的立体部件示意 |
| `set_map_view` | 定位国家或省份，切换地图与回放模式，开关电源设施图层，或回读地图设置 |
| `set_view_filters` | 改当前专题的日期、指标、地区或对照对象，保留其他筛选并校验发布范围 |
| `search_knowledge` | 在已审核文档的有效版本中检索关键词，返回证据和已标注的冲突 |
| `open_evidence` | 用证据 ID 打开可核对的原文片段及来源位置 |
| `export_result` | 下载项目内已保存的查询或图表输入数据，以及已完成的分析结果 |
| `save_project_view` | 按项目保存、列出和恢复命名视图，按需保留小云图表配置 |

地图定位和图层控制统一经总管登记动作，由浏览器应用后回读当前设置。数据子 Agent 有 `search_semantic_catalog`、`query_approved_metric` 和 `report_query_gap`。图表、分析选择器分别有 `select_chart` 和 `plan_analysis`。旧版地图问答入口单独使用目录和 UTC 时间工具。

## 页面匹配与机制解释

| 用户请求 | 执行 |
| --- | --- |
| 帮我切换到首页 | 打开 `/`，小云会话继续保留 |
| 我想看全国发电量这些年的趋势 | 打开「月度发电与省际比较」的长期走势 |
| 看 2025 年 5 月各省发电量排行 | 打开同一专题的省际排行，应用月份 |
| 看德国的历年 GDP 总量走势 | 打开经济专题并选中德国与 GDP 总量走势 |
| 看江苏多年逐月发电量趋势 | 现成全国趋势图的省级筛选只管单月排名及比较，检查对应的已发布省级数据 |
| 用立体示意解释风机如何并网 | 加载 `anatomy`，生成实体部件示意，并在当前页弹出可分步操作的模型 |

页面动作采用固定路由和各页独立的图表、筛选约束。进入数据审核页仍需独立审核令牌。图表能否显示数据取决于页面的当前发布版本和覆盖。经济与贸易专题可以导航，电力、气象、碳排放由已接入的数据库 Agent 查数。

运行时技能沿用 Anatomy 用实体结构解释技术机制的方法。小云填充经过校验的部件类型与说明，网站用 Three.js 的内置几何件渲染。设备无法显示 WebGL 时，用户仍能按部件阅读步骤。示意用定性模型讲解，网页不会安装或运行模型生成的代码。[Anatomy 源项目](https://github.com/wheresryan22/anatomy)

## 地图、证据与项目工具

| 用户请求 | 执行 |
| --- | --- |
| 电源地球定位到江苏，打开输电线路 | 用站内地名和线路目录解析，只更改目标区域与该图层 |
| 在当前经济体对比图把对照经济体换成日本 | 保留主经济体、年份与图表定位，核验新对照对象 |
| 请根据审核资料说明怎么用 MAE 比较模型，打开第一条证据 | 检索受审核的段落并用编号标注，证据卡可查看原文位置 |
| 把当前查询导出成 CSV | 用项目权限读取已保存的结果，保留筛选、发布版本、查询哈希、来源与缺测 |
| 把当前视图和选中图表保存为「月度发电」，然后恢复该视图 | 在项目内保存页面、筛选、实际发布版本及可重建的图表配置，按同一项目凭据恢复 |

筛选支持站内已有控件。月度发电的省级选项要验证所选发布版本中实际存在有值的地区，碳排放只接受发布数据或归档可核验的日期。没有可核验版本的省级请求会保留当前筛选并说明原因。经济体和年度筛选使用现有数据目录。保存视图能固定专题分析已显示的数据库版本或小云图表的数据引用。公开归档随应用版本更新。自定义制图的本地上传文件与临时编辑状态由其原有流程处理。

查询和小云图表输入支持 CSV 与 JSON 下载，已完成的分析保存为 JSON，以保留模型和任务数据引用。下载使用独立的项目权限校验。视图写入及恢复使用小云当前专题的项目会话。首次保存时可创建该专题的项目。同一项目同名保存会更新快照。

## 部署

数据库管理员在 V11 Agent 上下文和审计迁移后执行 [v11-xiaoyun-tools.sql](../scripts/v11-xiaoyun-tools.sql)，再部署应用。迁移创建项目视图表，以及知识文档、版本、段落和审核通过后可读的视图。初始语料是当前已发布业务规则的四个可回看段落。新增资料由管理员保存原文地址及内容哈希、版本、页码或段落定位，并审核版本和各段落。检索尊重有效日期，对已批准的历史引用仍可回看；标注相同 `claim_key` 和不同 `claim_value` 可报告冲突。当前检索使用分词和关键词匹配。

运行 `node --test scripts/verify-v11-xiaoyun.mjs` 检查工具与动作。配置临时 PGlite 后运行 `scripts/verify-v11-agent-policy-pg.mjs`，核验迁移重跑、审核可见性、来源冲突、项目隔离和下载保留的数据版本。
