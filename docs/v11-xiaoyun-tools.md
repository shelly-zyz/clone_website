# 小云总 Agent 的工具与站内动作

文字与语音转写共用浏览器提交和 Pi 总管。明确叫出页面名时，服务直接登记页面动作。像「看全国发电量这些年的趋势」这样的请求，由 Pi 按站内视图目录匹配图表。在同一请求里明确要切页和查数时，两个结果都可以返回。浏览器接收页面编号、图表编号及筛选，校验后切换页面。首页、地球工作台、专题总览、专题详情、自定义制图、区域回放和数据审核入口都在目录中。

## 总管可以调用的 13 个工具

| 工具 | 当前作用 |
| --- | --- |
| `load_skill` | 读取看板、预测回测或 Anatomy 机制解释的运行时说明 |
| `query_data` | 委托数据库子 Agent 查已发布指标，保存本轮结果并续办澄清 |
| `inspect_data` | 检查结果范围、粒度、质量和可用图表、分析，支持分析预检 |
| `render_chart` | 按查询结果出图，允许复用旧图输入更换图形和渲染器 |
| `render_dashboard` | 从已检查的单指标结果生成看板，附数据版本、口径和来源 |
| `submit_analysis` | 提交描述统计、聚类、预测、回测、比较或选模 |
| `get_analysis` | 读取已有分析任务状态和结果 |
| `get_sources` | 从已授权结果追溯数据版本与源链接 |
| `list_available_datasets` | 列出已发布指标、单位和口径 |
| `utc_now` | 读取 UTC 时间 |
| `find_site_views` | 发现真实站内页面、图表定位点、筛选参数及覆盖 |
| `navigate_site` | 切换到已注册页面，按支持的条件定位图表 |
| `render_mechanism` | 按因果顺序生成可旋转、缩放和分步查看的立体部件示意 |

旧的地球切换、地图定位和风电图层开关是工作台浏览器快捷动作。数据子 Agent 有 `search_semantic_catalog`、`query_approved_metric` 和 `report_query_gap`。图表、分析选择器分别有 `select_chart` 和 `plan_analysis`。旧版地图问答入口单独使用目录和 UTC 时间工具。

## 页面匹配与机制解释

| 用户请求 | 执行 |
| --- | --- |
| 帮我切换到首页 | 打开 `/`，小云会话继续保留 |
| 我想看全国发电量这些年的趋势 | 打开「月度发电与省际比较」的长期走势 |
| 看 2025 年 5 月各省发电量排行 | 打开同一专题的省际排行，应用月份 |
| 看德国的历年 GDP 总量走势 | 打开经济专题并选中德国与 GDP 总量走势 |
| 看江苏多年逐月发电量趋势 | 现成全国趋势图的省级筛选只管单月排名及比较，检查对应的已发布省级数据 |
| 用立体示意解释风机如何并网 | 加载 `anatomy`，生成实体部件示意，并在当前页弹出可分步操作的模型 |

页面动作采用固定路由和各页独立的图表、筛选约束。进入数据审核页仍需独立审核令牌。图表能否显示数据取决于页面的当前发布版本和覆盖。经济与贸易专题可以导航，电力、气象、碳排放由已接入的数据库 Agent 查数。

运行时技能沿用 Anatomy 用实体结构解释技术机制的方法。小云填充经过校验的部件类型与说明，网站用 Three.js 的内置几何件渲染。设备无法显示 WebGL 时，用户仍能按部件阅读步骤。示意用定性模型讲解，网页不会安装或运行模型生成的代码。[Anatomy 源项目](https://github.com/wheresryan22/anatomy)
