# 按地球项目整理的完整数据清单

> 版本：2026-09-08现场核验版  
> 适用范围：气象地球、电力地球、碳地球及三者共用的数据底座。  
> 阅读规则：“真实”不只有一种。观测、官方统计、业务预报、研究估算和模型情景都可以是真实来源的数据产品，但含义不同，绝不能互相冒充。

## 一、先看懂五种数据身份

| 身份 | 小白解释 | 可以怎样展示 | 不能怎样展示 |
|---|---|---|---|
| `observed` 观测/实测 | 仪器、场站或业务系统实际记录到的值 | “实际风速”“实际功率”“实际负荷” | 不能用模型输出替代 |
| `official_stat` 官方统计 | 政府或法定机构汇总发布的统计 | “2024年全国装机”“2023年省级平均排放因子” | 年度总量不能画成小时曲线 |
| `forecast` 正式预报 | 业务预报中心对未来天气的计算结果 | “GFS起报时间”“未来3小时预报” | 不能称实时观测或历史真值 |
| `research_estimate` 研究估算 | 论文/研究团队按公开方法估算的排放、潜力或资产 | “GRACED研究估算”“GISPO可开发潜力” | 不能称政府统计或现场监测 |
| `model_scenario` 模型情景 | 假设某种气候/政策路径后计算的未来可能结果 | “SSP1-2.6情景下2021—2060变化” | 不能称未来一定发生或实际发电 |

### 2.3 对截图的最终解释

截图给出的链条是：

`ERA5观测同化再分析 → WATCH方法偏差校正 → WFDE5陆地小时基准 → 与海洋ERA5组成W5E5/偏差校正基准 → 校正ISIMIP3b的CMIP6未来情景`。

因此项目清单应同时保留三个名字：ERA5是上游再分析，WFDE5是陆地偏差校正小时数据，W5E5是陆地WFDE5＋海洋ERA5的全球统一基准。当前项目实际已有的是经该体系处理的单一未来情景，并没有历史WFDE5/W5E5文件。
