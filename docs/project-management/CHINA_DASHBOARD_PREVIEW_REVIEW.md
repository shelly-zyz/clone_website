# 中国电力大屏预览审阅记录

> 预览版本：Unit 3 / 2026-09-09  
> 当前结论：本地预览已制作，等待用户视觉确认；Unit 4 尚未授权启动。

## 1. 如何查看

直接用浏览器打开：

`docs/design-references/china-dashboard/china-dashboard-preview.html`

这是无构建、无外部脚本依赖的静态预览包；省级 GeoJSON 和地形贴图位于相邻 `assets/`，需通过本地静态 HTTP 服务查看。推荐先以 1920×1080 查看，再缩到 1440×900。

## 2. 本轮需要用户确认的六件事

1. 中央地图是否足够突出，是否需要更大或更克制的 3D 倾斜。
2. 左侧“官方统计 / 映射样本 / OSM / 长期情景”的信息密度是否合适。
3. 右侧铺满竖栏的六个“预测工厂”工位，其像素小人、设备动画和论文图式产物，是否能直观表达预测加工过程。
4. 底部时间轴和来源账本是否应该常驻，还是生产页默认折叠来源。
5. 电力青＋质量琥珀的主站延续方向是否符合后续生产页面。
6. 中央中国地图已改用用户指定 `coastal-grid-dashboard` 的省级边界与地形/浮雕素材；请确认其地形质感和省份轮廓是否是进入 Unit 4 的视觉基准。

## 3. 已固定的真实性决定

- 2024 全国统计与 9,143 条地图设施样本永远分开。
- GFS 只称正式天气预报，GRACED 只称研究估算，VRE 只称模型情景。
- OSM 只展示众包几何/电压等字段，不展示虚构容量、损耗和潮流。
- 省级负荷、真实出力、调度、储能和实时碳强度均显示不可用。
- 没有真实功率标签和历史 NWP 前，模型、P10/P50/P90 和历史误差全部锁定。

## 4. 预览中的 UI 示意

以下只用于视觉审阅，不进入生产业务数据：`coastal-grid-dashboard` 的省级地形/浮雕材质、光点、线路流光、网格、趋势线形状、时间序号，以及预测工位中的像素小人、设备和产物切换动画。工位下方的时序曲线、样本库、配对曲线、热力矩阵、模型结构和滚动预测图借鉴用户提供论文图 4—8 的信息组织方式，但不是论文图片复制，也不是模型运行结果。
