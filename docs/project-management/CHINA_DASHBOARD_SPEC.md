# 中国电力大屏正式页面规格

> 版本：Unit 3 视觉确认稿（2026-09-09）  
> 状态：等待用户确认 HTML 预览；不是生产实现  
> 适用范围：PC 端中国电力专题大屏及 Unit 4 的数据契约、页面和性能验收  
> 上游：`CHINA_DASHBOARD_MVP.md`、数据资产清单、全网站来源清单、Unit 3 路线图

## 1. 页面目标与真实性边界

中国电力大屏是从电力地球进入的独立全国工作面，不是把地球放大。首屏以中央中国地图为主视觉，左侧解释“当前真实拥有的数据”，右侧用动画工位解释“预测如何加工、当前卡在哪一步”，底部统一控制时间与来源。

页面只允许五类可追溯数据身份：

| 身份 | 页面标签 | 含义 | 本页允许的例子 |
|---|---|---|---|
| `observed` | 实测 | 仪器、场站或业务系统实际记录 | 当前尚无可用于本大屏的省级风光功率、负荷或潮流 |
| `official_stat` | 官方统计 | 政府或法定机构汇总发布 | 2024 全国装机、发电量和电源/电网投资 |
| `forecast` | 正式预报 | 业务天气模式对未来的预报 | NOAA/NCEP GFS 当前起报与有效时间、100 m 风和短波辐射 |
| `research_estimate` | 研究估算 | 公开研究数据或遥感/众包产品 | GRACED Power、GISPO、光伏足迹、OSM |
| `model_scenario` | 模型情景 | 特定模式与 SSP 假设下的长期结果 | GFDL-ESM4 × SSP1-2.6 的 2021—2060 风光容量因子 |

以下内容在数据门槛通过前必须显示为“不可用/待补齐”，不能通过插值、动画或年度统计伪造：省级小时负荷、15 分钟/小时实际风光出力、供需缺口、真实省间潮流、储能运行、实时省级碳强度和超短期功率预测。

## 2. 视觉与布局规格

### 2.1 视觉基线

- 继承主站：深灰蓝背景 `#151d24`、电力青 `#00e5ff`、质量琥珀 `#fbbf24`、浅灰正文。
- 中央地图直接保留指定素材的青绿平原、黄褐高原与灰度浮雕纹理，再叠加轻微挤出和低强度青色电网辉光；禁止用单一蓝色滤镜覆盖土地地貌。
- 侧栏采用透明带状区域和细分隔线；只有可选择项目、重复数据单元和真正控件使用卡片边界。
- 数据值使用等宽字体；标题和操作使用主站无衬线字体。
- 实况/预报/研究估算/情景/不可用的视觉标签必须同时包含文字，不能只靠颜色区分。
- 左分析轨的四个数据分区在宽屏下按可用高度均匀展开，首尾与右侧预测生产线对齐，不在下方留下无意义空白。
- 预测产物图允许按步骤使用青、琥珀、洋红、黄绿、紫蓝和珊瑚红区分图形类型；状态仍须同时显示“作业中/已产出/待机/锁定”文字。

### 2.2 PC 目标分辨率

| 视口 | 目标 | 布局要求 |
|---|---|---|
| 1920×1080 | 宽屏主目标 | 左 320—360 px、中央弹性区、右 360—430 px；地图保持最大视觉锚点 |
| 1600×900 | 日常目标 | 左轨约 300—330 px、右轨约 360—410 px；保留完整顶栏和底部时间轴 |
| 1440×900 | 最低完整目标 | 左轨约 286 px、右轨约 360 px；预测工位和地图交互区不被遮挡 |
| 1366×768 | 降级 PC | 压缩统计副文案和来源列表高度；地图、预测锁定原因、时间轴必须可见 |
| 小于 1180 px | 非本 Unit 目标 | 显示“请使用 PC 宽屏查看完整大屏”的可访问提示；Unit 4 再决定平板模式 |

### 4.1 OSM 百万级数据硬边界

- 不允许把约 1,004,381 个 OSM 要素作为一个 GeoJSON 载荷送入浏览器。
- 输电线、电缆、变电站、电厂和发电机使用矢量瓦片或等价的服务端范围切片。
- 首屏只请求当前视口和当前缩放的瓦片；图层关闭时取消后续请求与交互索引。
- 发电机层默认在高缩放级别才显示；低缩放使用聚合或隐藏，避免 753,493 个细粒度组件造成拥塞。
- 单个设施详情允许返回完整几何；省级摘要与地图绘制载荷分开。
- 瓦片失败是局部图层错误，不得清空左侧统计或整个页面。
- Unit 4C 需记录每个缩放级别的瓦片数、传输字节、首帧耗时和交互帧率。

## 6. 交互规格

### 6.1 省份行为

1. hover：省份轻微抬升/描边；不触发数据请求。
2. click：写入 `scope=province` 和省级标准 ID，调整地图视角；左轨改为“该省已映射样本”，右轨显示该省训练输入仍缺，来源账本同步更新。
3. 没有样本：显示“当前筛选下无已映射样本”，保留覆盖率警告，不显示“省内无电站”。
4. 再次点击选中省份或点击“全国”：恢复全国范围；时间播放状态保持，地图视角可平滑复位。
5. 省级官方装机历史未接入前，不出现省份排名、同比或官方占比。

### 6.2 设施行为

- 只有真实来源返回的设施可点击；聚合点先展开或缩放，再进入单设施详情。
- 详情字段：名称、技术、运行状态、装机 MW、业主、投运年、来源、源记录 ID、坐标。
- 字段为 `null` 或源未提供时显示“未知”，不得猜测。
- 设施关闭/切层后清除详情；省份范围和时间轴不重置。

### 6.3 图层与不可用层

- 可用层按钮显示身份和时间；加载中、可用、陈旧、降级、不可用五态必须明确。
- 点击锁定层不切换地图，而是在原位展开缺口、原因和后续获取路径。
- GFS/GRACED 单层错误不影响设施和 OSM；来源面板不得因图层错误隐藏。

### 6.4 时间播放

- 预览时间轴为 `UI 演示`，步进只同步游标、地图脉冲、左侧趋势标记和右侧流程高亮。
- 生产时间轴按数据身份分模式：GFS 有效时刻、GRACED 日期、VRE 情景年份，不能用同一个“当前时刻”混播。
- 切换身份模式时先暂停，重设允许范围，再由用户继续播放。
- 省份/图层变化不重启播放；页面隐藏或性能压力过高时自动暂停动画。
- `prefers-reduced-motion` 开启时禁用地图浮动、流光和自动播放，仅保留静态状态变化。

## 7. 空状态、加载状态与错误传播

| 场景 | 页面行为 |
|---|---|
| 统计 JSON 不可用 | 官方统计槽显示“官方统计暂不可用”和来源文件，不用映射样本补值 |
| 数据库/资产 API 不可用 | 地图资产层关闭；全国官方统计和静态来源说明继续显示 |
| 当前省份无样本 | 显示范围、筛选条件和“无已映射样本”；提供返回全国操作 |
| OSM TileJSON/瓦片失败 | OSM 层标“地图瓦片不可用”；不下载百万级 GeoJSON 兜底 |
| PV 完整面缺失 | 展示真实年份/汇总和“精细面待结构化”，不画合成多边形 |
| GFS 无新批次 | 显示接口错误/旧成功起报/缓存陈旧；不生成天气场 |
| GRACED 日期缺帧 | 显示研究产品日期缺口；不插值成实时碳排放 |
| 预测输入未通过 | 预测链停在缺口节点，输出和回测槽保持锁定 |
| 地图边界加载失败 | 显示可恢复地图错误；侧栏、来源和返回按钮仍能工作 |

## 9. 性能与可访问性约束

### 9.1 Unit 4 验收预算

- 目标 PC（1920×1080）冷启动可交互时间：本地/同网环境 ≤ 3.0 s；地图骨架 ≤ 1.2 s。
- 1440×900 在已有缓存下范围/图层切换视觉响应 ≤ 150 ms；新数据请求 100 ms 内出现加载态。
- 地图连续操作目标 ≥ 50 FPS，最低可接受 P95 ≥ 30 FPS；`prefers-reduced-motion` 下不保留持续装饰动画。
- 首屏 JavaScript 与地图依赖需单独测量；是否引入 Three.js 只在预览通过后决定。
- OSM/PV/GFS/GRACED 载荷按视口、缩放、日期和图层限定；禁止超百万要素单包和无上限客户端索引。
- 失去焦点、不可见或页面离开时停止 RAF、计时器、粒子和未完成图层请求。

### 9.2 可访问性

- 所有按钮可键盘到达，焦点环与主站 `ring` 颜色一致。
- 图层状态、数据身份和不可用原因必须有文字；颜色不是唯一信息。
- 地图提供“当前范围/可见图层/所选设施”的文本等价信息。
- 图表应包含标题、单位、年份/时间和数据身份；锁定图表不暴露无意义的空 SVG 给读屏。
- 正文对比度达到 WCAG AA；关键数字最小 12 px，正文最小 11 px（1440 目标）。

## 10. Unit 3 预览与 Unit 4 生产边界

HTML 预览允许：用户指定 `coastal-grid-dashboard` 的中国省级边界与地形/浮雕视觉素材副本、UI 线路/光点动画、时间和流程 choreography、明确标注的界面占位。

HTML 预览不代表：官方边界精度、真实设施坐标、真实线路流向、真实省级指标、真实分钟级播放、可运行预测、实时碳强度或生产性能。

Unit 4 可以开始的必要条件：

1. 用户确认整体视觉方向、三栏比例、中央地图质感和信息密度。
2. 用户确认官方统计与映射样本的分栏表达。
3. 用户确认预测链以“锁定但可解释”的方式出现；允许明确标注为结构示意的论文图式小图，但不允许出现可被误读为业务结果的数值、坐标或曲线。
4. 用户确认时间轴同时支持不同数据身份分模式，而不是伪造统一实时态。
5. `CHINA_DASHBOARD_PREVIEW_REVIEW.md` 记录通过或需要修改的条目。
6. Unit 4 新任务继续以真实数据契约优先，不直接复制预览中的示意业务值/几何/动画数据。
