# 中国电力大屏通用MVP

> 定稿日期：2026-08-25  
> 产品定位：建设可复用的数据展示与预测组件，不把气象、电力、碳三个可视化硬编码成一个复杂联动情景。组件可以按真实数据条件复用到中国大屏、国家页或其他专题页。

## 一、第一版可以真实实现

### 1. 全国真实数据概览

- 数据更新时间、来源状态、数据库/缓存健康状态。
- 国家能源局和国家统计局的全国装机、发电量等正式统计。
- 地图数据覆盖情况单独展示，明确“地图设施汇总不等于官方总量”。

### 2. 中国电力设施地图

- GEM/WRI/水电数据集中的真实发电设施点位。
- OSM真实电厂、发电机、输电线和变电站图层。
- CPVPD-2024与ChinaPV 2015/2020真实光伏足迹。
- 点击设施显示名称、技术、状态、装机、来源和源记录ID；缺失字段显示“未知”。

### 3. 省份下钻的资产视图

- 按省筛选设施、技术类型和地图图层。
- 展示设施记录数和“地图已收录装机”，同时展示覆盖率警告。
- 暂不把地图设施汇总写成省级官方装机排名。

### 4. 真实气象与碳图层

- GFS刷新成功时展示真实预报；失败时显示“真实GFS暂不可用”。
- GRACED Power本地数据重建入库后展示真实研究数据产品及来源。
- 气象和碳只是可复用图层，不在MVP中强制组成复杂联合预测。

### 5. 统一来源与质量面板

- 每个图层显示来源、时间范围、分辨率、单位、真实类型、更新时间和已知限制。
- 页面任何数字均可追溯到文件、API或正式统计页面。

## 二、第一版必须暂缓

- 省级小时负荷、供需盈余/缺口：缺真实小时负荷。
- 省级实际风光出力和真实利用率：缺真实出力标签。
- 省间实时潮流和跨区调度：缺通道容量、损耗、成本和真实潮流。
- 储能调度：缺功率、容量、效率和SOC。
- 生产侧/消费侧电力碳转移：缺省级发电结构、排放因子和潮流。
- 复杂情景模拟：当前产品改为通用组件，不在中国大屏MVP中硬编码。
- AI、全双工语音：等待真实数据API和通用组件稳定后接入。

## 三、可复用超短期预测组件

预测作为展开页中的一个独立组件，不与三个地球强绑定。

### 组件输入

- 实体ID和类型；
- 历史真实功率序列；
- 带发布时间的NWP预报；
- 装机/可用容量；
- 时间范围、时区和质量标记。

### 组件输出

- 未来15分钟至4小时预测曲线；
- P10/P50/P90或其他经过校准的概率区间；
- 相似历史场景及相似度；
- 模型、数据版本、生成时间、时效和回测误差；
- 数据不足、模型超时或漂移时明确回退/拒绝，不生成假预测。

### 论文路线的产品位置

“GADF二维编码→CNN/聚类特征→欧氏距离精选样本→在线Seq2Seq训练”可作为该组件的高级模型。第一版先提供通用数据契约和简单基线；只有获得真实15分钟风电功率与历史NWP后，才能训练和验收高级模型。

## 四、文字页面原型

```text
┌ 顶栏：返回地球 | 中国电力 | 数据时间 | 真实数据健康状态 ┐
├ 左栏：图层、技术类型、年份/时刻、省份筛选               ┤
├ 中央地图：真实设施 / OSM电网 / 光伏足迹 / 可选气象碳图层 ┤
├ 右栏：所选省份或设施的来源、字段、质量和详情             ┤
├ 下方抽屉：                                               ┤
│  概览 | 资产列表 | 时间序列 | 超短期预测（有数据才启用） │
└ 底栏：来源链接、许可证、更新时间、缺失数据说明           ┘
```

## 五、MVP验收标准

1. 前端代码和接口中不再返回Demo、Mock或合成业务数据。
2. 中国设施、OSM电网、光伏足迹均能显示来源和数据日期。
3. 真实数据缺失时显示“暂不可用”及原因，不画假曲线或假地图点。
4. 官方统计与地图设施汇总分开，页面不得混用两个口径。
5. 省份筛选、设施点击、来源查看和返回状态恢复可正常使用。
6. GFS刷新成功时显示真实运行时刻；失败时接口和页面状态一致。
7. 数据库恢复后，对每个核心表记录行数、最早/最晚日期和缺失率。
8. TypeScript类型检查和中国数据校验脚本通过。
9. 超短期预测在没有真实标签前保持禁用；启用时必须通过时间滚动回测并显示误差。
