# 数据下载、入库与四类地球归档状态

更新日期：2026-07-27

## 数据口径

- 电力、气象预测与装机潜力的项目分析网格统一使用 0.5°。
- GRACED 碳排放源数据和碳地球可视化保持原生 0.1°。
- 碳排放只有在进入预测特征、区域统计或与 0.5°气象数据耦合时，才对副本执行 5×5 求和聚合；不得覆盖 0.1°源帧。
- GISPO 资源潜力源数据是 ERA5 2019、0.25°。数据库保存其来源假设，同时另建 0.5°项目聚合记录。该数据只作装机潜力和调度情景参考，不与 GFDL-ESM4 SSP1-2.6 的 2021–2060 序列直接混算。

## 数据库归档

- `website_data.dataset_catalog`：四类地球的统一数据目录与获取状态。
- `website_data.weather_forecast_fields`：真实 GFS 运行及全部气象字段。
- `website_data.climate_projection_sources`：Zenodo 20 个 NetCDF 的文件级状态、大小和 MD5。
- `website_data.climate_projection_daily`：气候投影的小时×位置日分块。
- `website_data.carbon_emission_frames`：GRACED 0.1°日排放源帧。
- `website_data.renewable_resource_potential`：GISPO 0.5°项目聚合潜力。
- `website_data.energy_assets`：发电与电网资产。
- `website_data.climate_vre_hourly`：区域风光容量因子和发电序列。

## 推荐下载顺序

1. 确认 RDS 已购容量和自动扩容策略。
2. 完成当前 Zenodo GFDL-ESM4 SSP1-2.6 的 20 个气候 NetCDF。
3. 获取 ERA5 token并生成时变风切变系数。
4. 获取省级小时负荷、实际发电和省间输电参数，先实现负荷预测与跨区调度。
5. 获取土地约束数据，计算项目自己的可装机上限。
6. 在容量允许后补齐 GRACED total、Industry 和 GroundTransportation。
