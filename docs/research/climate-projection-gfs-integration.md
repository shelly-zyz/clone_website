# 气候投影、GFS 与电力预测的数据衔接

## 结论

项目应把三类时间尺度不同的数据分开使用：

1. NOAA GFS：短期业务天气预报，用于未来 0—192 小时的滚动发电量预测。
2. Zenodo/ISIMIP：2021—2060 年长期气候情景投影，用于气候风险、资源变化和规划情景分析。
3. GISPO/净零论文：用于借鉴装机潜力、跨区输电、储能、弃电和调度优化框架，不作为短期天气或未来装机的真实预测。

## 当前基线

- 气候模型：GFDL-ESM4
- 情景：SSP1-2.6
- 空间范围：中国大陆
- 空间分辨率：0.5°
- 时间范围：2021—2060 年，逐小时
- 有效网格点：3,848
- 已有输出：风电、光伏容量因子
- 当前发电量换算：容量因子乘以当前数据库中的已投运装机容量

Zenodo 20501729 的原始气象点列表与现有
`VRE_gfdl-esm4_ssp126_2021_2060.mat` 的经纬度逐点、逐序号完全一致，
不需要重新做空间匹配。

## Zenodo 20501729

记录包含 21 个文件、约 27.36 GB：

- `huss`：近地面比湿，kg/kg
- `rsds`：地表向下短波辐射，W/m²
- `tas`：近地面气温，°C
- `sfcwind`：近地面风速，m/s
- `ps`：地表气压，Pa
- `VRE_*.mat`：风电和光伏容量因子

五个气象变量分别按 2021—2030、2031—2040、2041—2050、
2051—2060 四个十年文件组织。NetCDF 的实际维度为
`time × location`，不是完整规则栅格；每个时刻对应 3,848 个有效点。
时间采用 UTC+08。

## 论文中可直接复用的方法

长期气候变量来自 ISIMIP3b/CMIP6 的逐日投影，历史小时参考来自
1979—2019 年 WFDE5。论文用扩展类比法把逐日投影降尺度到逐小时：

- 对未来日 D 使用 D-1、D、D+1 三日气象序列；
- 在历史记录同一季节的 ±12 日窗口中寻找多变量最相似序列；
- 使用历史相似日的小时形状拆分未来日值；
- 缩放后保持未来日统计量，并尽量保持变量间物理一致性和跨日连续性。

该方法适合长期情景模拟，不应称为某一天的精确天气预报。

风电容量因子由风速、气温、比湿、气压、风切变和机组功率曲线计算；
光伏容量因子由短波辐射、气温、风速、组件温度和逆变效率计算。
风切变应使用随月份和小时变化的参数，不应固定为单一常数。

## NOAA GFS

GFS 0.5°产品每天运行 4 次（00、06、12、18 UTC），0—192 小时按
3 小时输出。NOMADS Grib Filter 是公开 HTTPS 接口，不需要账号。

当前气象地球使用：

- 10 m U/V 风；
- 2 m 气温；
- 2 m 相对湿度；
- 地表 CAPE；
- 海平面气压；
- 整层可降水量。

若要严格驱动论文的风光发电公式，还应增加：

- 100 m U/V 风，或月—小时风切变系数；
- 2 m 比湿 SPFH，或由温度、湿度、气压换算；
- 地表气压 PRES，不能用海平面气压直接替代；
- 地表向下短波辐射 DSWRF；
- 阵风、降水、云量等极端天气变量。

GFS 的辐射、降水等变量可能是预报区间累计量或平均量，必须依据
`stepRange` 做时间对齐。

## 与当前项目的兼容性

| 项目 | 结论 |
|---|---|
| Zenodo 原始气象与现有 VRE 网格 | 完全一致 |
| GCM、SSP 与现有 VRE | GFDL-ESM4/SSP1-2.6 完全一致 |
| 时间长度 | 350,640 小时一致，包含闰年 |
| 时区 | Zenodo 为 UTC+08；GFS 为 UTC，入模前必须统一 |
| 未来发电量 | 当前装机容量保持不变，只是“固定装机下的气候驱动发电情景” |
| 风电技术 | 论文陆上风电假设不能直接代表海上风电 |
| 光伏技术 | 集中式与分布式/屋顶光伏应分开处理 |
| 其他 GCM/SSP | 应作为独立情景运行，不能与 SSP1-2.6 小时值直接拼接 |
| GISPO 资源数据 | 基于 ERA5 2019 和不同技术、土地假设，不能替代当前未来气候基线 |

当前构建脚本把海上风电归入统一 `wind` 装机，但论文的中国陆地点列表和
土地过滤不代表海上风资源；后续应拆分陆上风电与海上风电。当前光伏也应
逐步拆分集中式与分布式/屋顶光伏。

## 建议的预测与调度链路

短期链路：

`GFS → 气象特征 → 容量因子 → 可用发电量 → 负荷预测 → 跨区调度 → 碳排放`

长期链路：

`GCM/SSP 情景 → 容量因子 → 装机情景/装机上限 → 跨区输电与储能优化 → 排放情景`

发电量的基础关系为：

`可用发电量 = 容量因子 × 对应技术和区域的装机容量`

实际并网发电还要扣除检修、故障、弃风弃光、限电、线路拥塞和储能损耗。
因此装机容量只是必要条件，不是完整预测。

## GISPO/净零论文的合理用法

可复用：

- 网格或区域节点；
- 最大可装机容量与 installation factor；
- 逐小时供需平衡；
- 跨区输电流向和线路容量；
- 储能、弃电、缺电、备用约束；
- 成本、碳排和可靠性多目标情景。

不应直接复用：

- 2050 年优化装机作为真实预测；
- ERA5 2019 的单年容量因子替代 2021—2060 气候情景；
- 强制净零约束作为系统唯一运行目标；
- 在不校准技术、土地和装机年份时直接导入论文结果。

建议把“净零”设为可切换情景，把主模型目标改为成本、弃电、缺电、
碳排和跨区输电的多目标优化。

## 数据库设计

原始 NetCDF 采用单文件暂存、MD5 校验、逐日入库、成功后删除暂存文件。
数据库保存：

- Zenodo 文件、模型、情景、变量、许可和 MD5；
- 一份 3,848 点压缩坐标表；
- 每天一份 `24 × 3,848` gzip Float32 数据块；
- 单位、时区、日期、最小值、最大值、均值和缺失值计数。

这种结构避免把 27 GB 同时放在本地，也避免把逐小时逐格点拆成数亿条
普通关系行。
