# 中国大屏 HTML 预览视觉检查表

> 检查对象：`china-dashboard-preview.html`  
> 检查范围：Unit 3 的视觉、布局、交互和真实性表达；不是 Unit 4 生产功能验收。

## A. 第一眼与层级

- [x] 首屏明确写“中国电力”，不是沿海专题或放大的地球。
- [x] 中央中国地图是最大视觉锚点，左右信息不会盖住主体。
- [x] 左侧回答“现在有什么真实数据”，右侧回答“预测为什么还不能用”。
- [x] 深灰蓝、电力青和质量琥珀延续主站，不出现新的紫色 SaaS 主题。
- [x] 侧栏以带状分区和细分隔线为主，没有堆叠重型卡片墙。

## B. 数据真实性

- [x] 2024 全国装机、发电量、投资标为“官方统计”。
- [x] 9,143 条设施标为“映射样本”，与官方统计分开。
- [x] OSM 数量标为“众包地图”，不写调度容量或真实潮流。
- [x] VRE 写明 GFDL-ESM4、SSP1-2.6、2021—2060 和“模型情景”。
- [x] GRACED 写“研究估算”，GFS 写“正式预报”。
- [x] P10/P50/P90、模型结果和历史误差保持锁定；论文图式曲线明确标注“结构示意”，无业务数值。
- [x] 所有 UI 示意几何和 choreography 在页面/来源文档中有说明。

## C. 交互

- [x] 点击省份热区/快捷按钮时，地图焦点、左侧范围和右侧工位状态同步更新。
- [x] 点击“全国”可恢复全国范围。
- [x] 播放/暂停推进时间游标、地图脉冲、趋势标记和六个预测工位。
- [x] 当前工位的像素小人、工具和设备运行灯进入逐帧动画；已产出工位保留下方对应可视化内容。
- [x] 六种产物分别为气象双线图、时序样本库、配对时序、质量热力矩阵、模型结构图和滚动预测图。
- [x] 点击不可用层显示明确原因，不切换到假图层。
- [x] 来源账本可展开/收起，且焦点状态可见。
- [x] `prefers-reduced-motion` 下持续动画与自动播放停用。

## D. 布局与可读性

- [x] 1440×900 截图：顶栏、两侧轨、地图、预测锁定原因和底部时间轴无重叠。
- [x] 1920×1080 截图：地图仍是主轴，左右留白与信息密度均衡。
- [x] 左侧四个数据分区按栏高展开，宽屏下没有大块无意义底部空白。
- [x] 六张预测产物采用分步科研配色，暗色底上仍保持足够亮度和辨识度。
- [x] 1366×768 规则会压缩次级文案，不隐藏真实性标签。
- [x] 小于 1180 px 显示 PC 宽屏提示，不强行挤压成不可读布局。
- [x] 键盘焦点、按钮语义、aria-live 和文字状态存在。

## E. Unit 4 约束是否显眼

- [x] 页面明确写“规格预览 / 非实时运行页”。
- [x] 地图明确写“视觉示意几何；生产接入真实边界/瓦片”。
- [x] OSM 说明首屏不得加载百万级 GeoJSON。
- [x] 省级无值显示 `—` 或“待生产查询”，不显示看似真实的业务数。
- [x] 预测解锁条件包含真实功率、历史 NWP、容量、停机/限电和质量码。

## F. 浏览器实测记录

浏览器验证已于 2026-09-09 完成。页面通过本机静态 HTTP 服务打开，避免浏览器对 `file://` 的安全限制；页面本身仍是无构建、无外部脚本依赖的 standalone HTML。
